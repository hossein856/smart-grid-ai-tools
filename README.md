# Smart Grid AI Tools (Load Forecasting)

A lightweight, open-source Python library designed to bridge Electrical Engineering and Artificial Intelligence. This tool provides foundational scripts to analyze historical power grid data and apply machine learning algorithms for short-term load forecasting.

## Features
* Data preprocessing utilities for smart meter and grid data.
* Implementation of baseline AI models (e.g., Linear Regression, Random Forest) for predicting power consumption.
* Modular design for easy integration into broader power system automation workflows.

## Motivation
As power grids become smarter, integrating AI for demand forecasting and fault detection is critical. This project aims to provide accessible, open-source tools for electrical engineers and AI researchers to collaborate.
